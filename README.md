# 🎮 E-Commerce Gamer - Protótipo de UI/UX (cod_front_end_t07df)

Projeto de planejamento e design de interface gráfica (Front-End) focado na experiência do usuário para um e-commerce voltado ao universo gamer. Desenvolvido como atividade avaliativa para o SENAI.

## 🚀 Tecnologias e Ferramentas Utilizadas
* **Figma** (Prototipagem de Baixa e Alta Fidelidade)
* **Unsplash** (Banco de imagens gratuito para mídia gamer)

## 📐 Estrutura do Projeto
O escopo foi dividido em dois níveis de fidelidade para validar a arquitetura antes da programação:

1. **Protótipo de Baixa Fidelidade (Wireframes):** Esboço estrutural focado no fluxo do usuário para Desktop e Mobile.
2. **Protótipo de Alta Fidelidade:** Design visual polido utilizando paleta de cores moderna (modo escuro), contraste em verde neon, botões de ação estruturados e mídias contextualizadas.
